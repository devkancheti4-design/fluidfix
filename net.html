the growth rule

The law says which way

A node is one fluidfix over one territory, one fault class and one line range. Its refusal already carries a ruling, so nothing extra has to be invented to steer the search.

Refuted — every candidate it generated was rejected by the suite. The fault is not in this class here, so the net opens the other classes this territory can exhibit and this class in further territories.

Cut short — a candidate passed but the view was capped, or the clock ran out with the failure still pointing here. The net splits that node's line range in two and gives each half its own fluidfix.

One correction the runs forced: a remembered class is evidence about the class, not about the territory. Until a refusal on it moved territory first, a warm search crawled exactly like a cold one — 129 nodes instead of 13.

Where a fixed plan already contained the answer the net is four times slower (60 nodes against 45 on rich table.py). Where it did not, the net is the only one that finds the fault. And a remembered shape is worth what its scarcity is worth: arrow\u2019s class matched one territory of ten, so the search was a single node and two suite runs.

measured on 240 generated bugs, six shapes, each with a test that catches it

A table grows. A shape does not.

Every bug in this stream is distinct: its own names, values and surroundings. After each one, three arms are scored on the next twenty-four they have never seen — and every repair, in every arm, is accepted only because that bug's own test passed.

A table of whole programs never once repaired a bug it had not been handed: 240 rows, nothing to show for them. A table of broken lines does better, because the same line does recur, but it needs a row for each and still misses more than half. Six shapes repaired every one of the 240, and the six never became seven.

So can it write a fix it has never seen? Yes for a line: a shape is a signal and a transform, so it produced a correct repair for lines, names and values that were not in any example — that is what the right-hand chart is. No for a class: a fault whose shape nobody has written is refused, not guessed. New shapes come from a person, or from a model that authors one and submits it to the same test.
