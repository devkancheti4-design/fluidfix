Fluidfix and the Life

memory empty

Two tools, fused both ways. Fluidfix owns a vocabulary of fault shapes and the rule that only a test may accept a fix. The Life owns a memory that abstains when it does not know and a confidence gate that routes. Put the shapes in the Life's free tier and it repairs instead of only naming. Put the Life above many fluidfixes and the second incident costs one of them instead of forty-five.

Shapes in the free tier

The Life Debugger's first tier names a bug and cannot repair it, and a fix from its model tier is trusted on sight. Fluidfix's shapes propose a correction for any line whose signal matches, the caller's own test accepts or rejects it, and a rejected candidate is rolled back exactly. The model's answer now faces the same test before it is believed.

A memory above the fan-out

One guard searching a repository can open the wrong file and never recover. Many small fluidfixes, one per file and fault class, cover instead of rank, and the first green ends the search. The judge above them keeps a Life: the signature of the failure, and which territory and class answered it.

The last row is the recursion paying off: a signature never seen before, in a different repository, but the class that answered last time leads the fan-out. Its winner needed two suite runs.

  • level 0Inside one fluidfix. The taught vocabulary proposes, the suite judges, a candidate that fails is rolled back byte-exact, and a refusal is reported with the test that killed each attempt.
  • level 1The judge over many. A Life keyed by the failure signature, read through the gate w = t/(t+C). Above the gate, one fluidfix. Absent, it abstains into the fan-out and learns the winner.
  • level 2The same organ, coarser key. Which classes have ever answered. A new signature inherits the order of the fan-out from it, so the lesson crosses repositories even though the signature does not.
  • level 3A judge over judges. The same table keyed by repository instead of by file. Nothing in the structure changes, only the key — which is what makes it recursive. This level is drawn here but has not been measured.
