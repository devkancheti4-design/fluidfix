what we could grow into

Everything below this line is unmeasured

None of the following has been measured. It is what the mechanism permits, with the thing that would have to be true written under each one. It is kept apart from the page above on purpose — the measurements are the only reason to believe any of it.

A gate on every merge

The six checks run against a pull request: nothing merges unless red became green, stayed green, broke nothing, and has no rival that also passes.

needs: a CI integration, and a false-refusal rate measured on real PRs

Self-healing CI

A red build repairs itself where the fault is mechanical; where it is not, it opens an issue already naming the file, the classes eliminated and the test that killed each candidate.

needs: shape coverage of real incidents — the number we do not have

Learning one team's history

Point the budget ladder at a year of resolved failures and let the kinds that recur become taught classes, the way two were written from its own output this week.

needs: a real incident history, not a corpus we generated

A verifier for agent-written code

The judge does not ask who wrote the patch. An agent proposes, this decides, and nothing merges on the agent's own say-so.

needs: proof the localisation makes the model cheaper — untested

The honest next step is not another benchmark. It is one repository, in report-only mode, for a week — real failures, sorted into kinds. That produces the one number none of our runs can: what fraction of incidents that actually happen are mechanical.

Every node is one small guard over one file and one fault class, and the project's own test suite is the only thing allowed to accept anything. Rejected candidates are rolled back byte-exact.
